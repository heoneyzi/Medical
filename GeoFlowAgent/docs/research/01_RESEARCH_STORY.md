# 단계별 연구 이야기

[← 연구 안내](../README.md) · [실험 목록 →](02_EXPERIMENT_MAP.md)

이 연구는 두 질문에서 출발했습니다.

1. **동결(frozen)된 언어모델의 임베딩 공간을 도구 실행 계획에 쓸 수 있는가, 그리고 그 공간이 유효하다는 것을 어떻게 증명하는가.**
2. **그 공간 위에서 계획하는 에이전트가, 실제 생물학 데이터와 도구를 쓸 때 도구를 하나씩 따로 부르는 것보다 정답에 더 가까이 가는가.**

좋은 공간이란 문장이 비슷하면 가까운 공간을 넘어, **현재 상태에서 어떤 행동이 목표에 가까워지는지** 구분하는 공간입니다. 에이전트는 FlowAgent(latent flow-matching 계획)의 아이디어를 가져와, 공개된 동결 인코더 위에 실행 환경 · 학습 모듈 · 평가를 직접 구축했습니다.

실험이 남긴 가장 중요한 교훈은 **"표현 안에 정보가 있다", "거리로 그 정보를 읽을 수 있다", "실제 행동을 잘 고른다", "과제 전체를 완수한다"가 서로 다른 성과**라는 것입니다. 아래 다섯 단계는 이 네 가지를 하나씩 분리해 가는 과정입니다. 각 수치는 해당 단계의 데이터와 평가 조건에서 얻은 결과이며, 단계를 합친 하나의 성공률이 아닙니다.

---

## ① 합성 파일럿 — 시스템은 동작했지만, 환경이 정답을 알려 주었다

**설계.** 12개의 합성 과제(train/dev/test 7/2/3)에서 8개의 유전체 분석 도구를 조합해 "보고서가 준비된 상태"에 도달하는 문제를 풀었습니다. Qwen2.5-1.5B·7B, MedCPT, SapBERT, DNABERT-2를 동결 인코더로 쓰고, 임베딩 캐시 → 거리 학습 → flow 학습 → 에이전트 실행까지 연결했습니다. 거리 6종을 dev에서 비교해 bilinear를 고른 뒤 test를 평가했습니다.

**결과.**

| test (3 시드 평균, 과제 3개) | Qwen2.5-1.5B | Qwen2.5-7B |
|---|---:|---:|
| 학습된 bilinear 거리의 행동 정확도 | **0.8551** | 0.7681 |
| flow 첫 행동 정확도 | 0.4359 | 0.4744 |
| 무작위 정책 + 정확한 계약 + 올바른 STOP | 1.0000 | 1.0000 |

**해석.** 작은 학습 모듈은 행동 순위를 잘 매겼지만, 계약만 정확히 주면 무작위 정책도 모든 test 과제를 풀었습니다. 실행 가능한 도구 집합이 사실상 최적 행동 집합과 같았기 때문입니다. **성공률이 높아도 환경이 답을 정해 주면 학습 모델의 가치를 증명할 수 없습니다.** 좋은 행동 순위가 좋은 전체 계획으로 자동으로 이어지지도 않았습니다.

**다음 단계로.** 계약이 정답을 알려 주지 않는 환경, 그리고 정답 경로 하나가 아니라 모든 최적 행동을 기준으로 채점하는 방법이 필요했습니다.

## ② 탐색 파일럿 — 정답 경로 하나 대신, 정확 탐색

**설계.** 실행 환경을 끝까지 탐색해 모든 상태의 최소 잔여 비용(V\*)과 최적 행동 집합을 계산했습니다. 실행은 가능하지만 비싸거나 품질이 낮은 도구, 대체 경로, 복구 상황을 넣어 계약만으로는 정답을 알 수 없게 했습니다. 210개 과제(128/41/41)에서 value geometry, Search-DAgger, State Flow를 학습하고, 한 번에 계획 · 관측 후 재계획 · 같은 계산량의 blind 재계획을 비교했습니다.

**결과.** 관측 후 재계획의 목표 완수율은 **0.8630**으로, 한 번에 계획(0.5731)과 blind 재계획(0.0859)을 크게 앞섰습니다. 반면 동결 임베딩과 해시 임베딩의 차이는 시드 편차 안에 있었고(0.9617 vs 0.9578), 무작위 정책도 교란 상황에서 41/41을 성공했습니다.

**다음 단계로.** 재계획 효과라는 첫 신호를 얻었지만 문제는 여전히 쉬웠습니다. 도구를 늘리고, 되돌릴 수 없는 선택과 미끼 도구를 넣은 hard-v2를 만들었습니다.

## ③ hard-v2 — 어려운 합성 벤치마크와 사전등록된 1회 test

**설계.** 240개 과제(144/48/48), 도구 50개, snapshot 3,042개. 기하 9종, 파라미터 수를 맞춘 입력 조합 12개, 해시 대조군, 용량 곡선, Search-DAgger, State Flow를 모두 dev에서 비교했습니다. 최종 후보(MedCPT-only + cosine + 2배 용량 head)와 사전등록한 기준 모델(전체 multi-view + DAgger round 2)을 고정한 뒤, test 48개를 한 번 평가했습니다. test 접근은 모두 hash-chain 기록으로 남겼습니다.

**dev에서 선택을 결정한 비교** (48개 과제, 3 시드, 짝지은 task-macro 차이):

| 비교 | 정책 정확도 차이 [95% CI] | 읽는 법 |
|---|---|---|
| MedCPT-only − 전체 multi-view | +0.1356 [+0.0747, +0.1927] | 모든 표현을 단순히 합치면 오히려 나빠짐 |
| MedCPT-only cosine − 파라미터를 맞춘 해시 cosine | +0.1347 [+0.0784, +0.1876] | MedCPT 표현에 행동 정보가 있음 |
| 전체 동결 cosine − 파라미터를 맞춘 해시 cosine | −0.0009 [−0.0332, +0.0315] | 이득은 "동결"이 아니라 어떤 표현을 고르느냐에서 옴 |
| MedCPT cosine − MedCPT Poincaré | +0.0639 [+0.0491, +0.0784] | 쌍곡 기하는 이득이 없었음 |

**test 결과.**

| 지표 | 선택된 MedCPT 모델 (3 시드) | 사전등록 기준 모델 |
|---|---:|---:|
| 최적 행동 정책 정확도 ↑ | **0.8010** | 0.6875 |
| STOP·행동 결합 정확도 ↑ | **0.7364** | 0.6702 |
| Regret@1 ↓ | **0.1403** | 0.3848 |
| 목표 완수율: 한 번에 계획 / **관측 후 재계획** / blind | 0.1233 / **0.4028** / 0.0000 | |
| 에피소드 성공률 (clean) | 0.6667 | 0.6458 |

**해석.**

1. **어떤 동결 표현을 고르는지가 중요했습니다.** 여러 표현을 이어붙인 모델보다 MedCPT 하나가 좋았습니다.
2. **복잡한 거리가 자동으로 유리하지 않았습니다.** 비대칭·쌍곡 거리 대신 단순한 cosine이 최종 선택이었습니다.
3. **관측을 반영한 재계획이 결과를 바꿨습니다.** 같은 계산량의 blind 재계획은 0.0000에 머물러, 효과가 관측 자체에서 나온다는 것을 보여 주었습니다.
4. **순위 개선이 에피소드 성공률에 옮겨 가는 폭은 작았습니다**(0.6667 vs 0.6458). 교란 상황에서는 계약을 준 무작위 정책도 0.6667에 도달했습니다.

**다음 단계로.** 합성 환경에서 답이 나왔으므로, 불렀지만 쓸모없는 도구 호출이 실제로 존재하는 전문가 기록으로 옮겨 갔습니다.

## ④ GeoACMG — 실제 전문가 기록 위의 변이 해석

**왜 임상 변이 해석인가.** 이 분야는 계획이 의미를 갖는 세 조건을 모두 갖추고 있습니다. 변이 하나를 분류하려면 근거 코드마다 서로 다른 데이터베이스를 봐야 하므로 **도구 다양성**이 데이터에 강제되어 있습니다. ClinGen Evidence Repository는 전문가 패널이 적용한 근거(Met)와 검토 후 기각한 근거(Not Met)를 공개하므로 **단계별 정답**이 있습니다. 그리고 Not Met 덕분에 **불렀지만 0점인 도구 호출**까지 환경에 들어옵니다.

**설계.** ClinGen 기록 13,278행에서 과제 4,054개를 만들고 유전자당 최대 100개로 제한해 2,921개를 구성했습니다(train 1,753 / dev 584 / test 584, 유전자 155개). train+dev에서 정확 탐색한 상태는 448,704개입니다. 동결 MedCPT 벡터 위에 기하 5종(cosine, Euclidean, Poincaré, directed quasimetric, pair MLP) × 시드를 학습했습니다. 분석 전에 주장 B0와 C1–C5, 그리고 각 주장의 반증 조건을 사전등록했습니다. 과제는 전문가 기록을 오프라인 snapshot으로 재생하고, 도구 비용은 probe 1.0, report 0.5로 고정했습니다.

**결과.** (B0는 코퍼스 전체, 나머지는 584개 개발 과제)

| 분석 | 알고 싶었던 것 | 얻은 답 |
|---|---|---|
| B0 벤치마크 진단 | 정말 여러 도구가 필요한가? | 가장 좋은 단일 도구군으로 풀리는 과제는 0.3102뿐 — 격차 **0.6898** [0.6323, 0.7391] |
| 동결 공간 probe | 실행 정보가 벡터에 있는가? | 유전자 홀드아웃 probe에서 잔여 비용 R² **0.3355**(무작위 사영 −0.0173), 다음 행동 정확도 0.5523(우연 0.2896) |
| 원시 거리 | 그 정보가 단순한 거리로 읽히는가? | cosine 0.5055, L2 0.5078, 내적 0.4966 — 우연 수준 |
| 기하 5종 × 3 시드 | 작은 학습 모듈이 그 정보를 읽는가? | 자기 에너지 정렬 0.5870(Euclidean) ~ 0.8266(pair MLP), 정책 정확도는 0.8512 ~ 0.8699로 차이가 작음 |
| R1 파라미터·초기값 정합 | 파라미터 수 때문인가? | 총 파라미터 335,942개, 같은 초기 trunk에서도 cosine − Euclidean 정렬 차이 +0.1432 [0.0950, 0.1802] (5 시드) |
| R1b 새 시드 | 다시 학습해도 행동 우위가 같은가? | 시드 59/71에서 정책 차이 −0.0099 — 기존 cosine 우위가 뒤집힘 |
| R2 readout 분해 | 학습 공간은 자기 에너지로만 읽히는가? | 자기 에너지 0.7405, 표준화 cosine 0.7199, 일반 cosine 0.5761 — 표준화로 대부분 복원 |
| R4 교차 모델 대조 | 정렬 품질이 정책 품질을 만드는가? | 같은 모델과 다른 모델의 상관이 거의 같아(+0.3282 vs +0.3289) C5("계획기 유효성 = 표현 유효성")를 철회. 정합 차이는 +0.000424로 매우 작음 |
| R7 State Flow | 관측 후 재계획이 여기서도 도움이 되는가? | 목표 완수율 **0.5993** vs 한 번에 0.1169 vs blind 0.0274, 차이 +0.4824 [0.4439, 0.5223] |

**해석.** 합성 단계와 달리 대부분의 과제는 한 종류의 도구로 풀 수 없는 진짜 계획 문제였습니다. 동결 MedCPT 벡터에는 실행 정보가 있었지만 원시 거리로는 읽히지 않았고, 학습된 모듈이 그 정보를 **읽는 방법**을 배웠습니다. 기하 사이의 정렬 차이는 컸지만 행동 차이는 작았고 새 시드에서 방향이 바뀌었습니다. 관측 후 재계획은 여기서도 가장 뚜렷한 효과였습니다.

**다음 단계로.** 기하 효과가 시드와 readout을 바꿔도 유지되는지, 그리고 에이전트가 MedCPT를 실제로 쓰는지 확인했습니다.

## ⑤ 후속 분석 — 시드, readout, 제거 실험

**설계.** cosine과 Euclidean을 7개 시드(17/29/43/59/71/83/97)로 늘려 두 가지 기준의 신뢰구간을 계산했습니다. 시드 기준은 "다시 학습해도 같은가", 유전자 기준은 "유전자가 바뀌어도 같은가"를 묻습니다. 여기에 동결 공간의 readout 사다리(R8), MedCPT와 학습 없는 64차원 구조화 상태 해시의 분리(R9), 기하 5종 × readout 6종 순위(R10), MedCPT를 0으로 바꾼 재학습(R11)을 더했습니다.

**결과.**

| cosine − Euclidean, 7 시드 | 차이 | 시드 CI | 유전자 CI |
|---|---:|---|---|
| 정렬 · 자기 에너지 | **+0.1523** | [0.1152, 0.1783] | [0.1157, 0.1868] |
| 정렬 · 표준화 cosine | +0.0197 | [−0.0180, 0.0485] | [−0.0007, 0.0291] |
| 정렬 · whitening cosine | −0.0368 | [−0.0870, −0.0146] | [−0.0457, −0.0286] |
| 정책 정확도 | +0.0068 | [−0.0033, 0.0153] | [0.0016, 0.0148] |
| Regret@1 | −0.0208 | [−0.0462, 0.0083] | [−0.0288, −0.0137] |

| 추가 분석 | 결과 |
|---|---|
| R8 동결 공간 readout | train에서 맞춘 표준화 L2 0.5663, whitening cosine 0.5508, 무작위 64차원 사영 0.5981 — 단순한 선형 readout만으로도 우연을 넘음 |
| R9 정보원 분리 | 구조화 해시만으로 0.7054, MedCPT를 더해 0.7040 — 정렬 신호의 상당 부분이 워크플로 구조 자체에서 나옴 |
| R10 기하 순위 | 기하 5종 × readout 6종에서 서로 다른 순위 5개, 1위를 차지한 기하 4종 |
| R11 MedCPT 제거 | regret **+0.0441** (run CI [0.0260, 0.0631], 유전자 CI [0.0011, 0.0683]) — 에이전트가 MedCPT를 실제로 활용 |

**해석.** cosine의 큰 정렬 우위는 각 모델을 자기 에너지로 읽을 때만 나타났고, 읽는 방식을 바꾸면 줄거나 뒤집혔습니다. 정책과 regret에서는 유전자 기준 구간이 0을 배제한 반면 시드 기준 구간은 0을 포함해, **유전자 간 일반화와 재학습 안정성이 별개의 질문**임을 보여 주었습니다. MedCPT를 지우면 regret이 나빠졌으므로 에이전트는 워크플로 구조와 MedCPT를 함께 활용합니다.

## 결론과 마무리

1. **관측 후 재계획이 가장 확실한 개선입니다.** hard-v2 test(0.4028 vs 0.1233)와 ClinGen 과제(0.5993 vs 0.1169)에서 모두 한 번에 계획하는 방식을 크게 앞섰고, 같은 계산량의 blind 재계획은 실패했습니다.
2. **동결 모델의 공간에는 실행 정보가 있고, 학습된 readout이 그 정보를 읽어 냅니다.** 원시 거리는 우연 수준이었고, 작은 학습 모듈이 정렬을 되살렸습니다.
3. **가장 좋은 기하는 읽는 방식에 따라 달라집니다.** 특이한 거리를 고르는 것보다 어떤 입력을 쓰고 어떻게 읽을지가 더 중요합니다.

**여기서 마무리한 이유.** ⑤까지 마치자 각 질문에 답이 나왔습니다. 재계획 효과는 사전등록 test를 통과했고 ClinGen 과제에서도 재현되었습니다. 기하 질문은 1위가 readout과 시드에 따라 바뀐다는 답으로 정리되었습니다. ClinGen test 분할은 안정적인 사전등록 주장 하나를 단 한 번 확증하기 위해 남겨 둔 것이고, ⑤의 결과는 그렇게 확증할 만큼 안정적인 기하 주장이 없다는 것을 보여 주었기에 연구를 세 결론으로 마무리했습니다. 이 결론이 가리키는 다음 질문, 즉 재계획이 실제 도구 비용까지 줄이는가는 비용을 측정할 수 있는 실제 유전체 도구(MARRVEL 프로토콜) 위에서 다룰 질문입니다.

## 이 연구 방식에서 남는 것

- **"임베딩이 유용하다"를 하나의 숫자로 뭉개지 않았습니다.** probe에는 정보가 보이지만 원시 거리에는 보이지 않는 경우, 정렬은 좋아졌지만 정책은 반대로 움직인 경우를 분리했습니다. 무엇을 학습시키고 무엇을 평가할지 정하는 직접적인 근거가 됩니다.
- **대조군으로 설명을 하나씩 걸러 냈습니다.** 계약, STOP, 입력 표현, 파라미터 수, 초기값, 시드, 관측 feedback을 차례로 통제했고, 그 과정에서 처음의 유리한 설명을 여러 번 고쳤습니다. 부정적 결과와 정정 이력도 연구의 일부로 남겼습니다.
- **결과를 다시 계산할 수 있게 남겼습니다.** 과제별 지표, 설정, 사전등록과 test 접근 기록이 있어, 요약된 숫자뿐 아니라 주장을 다시 계산하고 반박할 수 있는 근거가 함께 남아 있습니다.
