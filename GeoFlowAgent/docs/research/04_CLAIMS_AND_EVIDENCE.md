이 연구의 각 주장이 어떤 근거에 서 있는지 정리했습니다. 수치의 출처와 재계산 방법은 [03](03_RESULTS_AND_VERIFICATION.md)에 있습니다.

## 근거를 읽는 기준

- **test 근거** — dev에서 모든 선택을 마친 뒤, 사전등록한 test에서 한 번 평가한 결과입니다. hard-v2의 결과가 여기에 해당합니다.
- **dev 근거** — 저장된 데이터와 대조군으로 확인한 결과입니다. GeoACMG의 584개 개발 과제 결과가 여기에 해당합니다.
- **구간 읽는 법** — 95% 구간이 0을 배제하면 차이의 방향을 지지하고, 0을 포함하면 방향을 판정하지 않고 `UNRESOLVED`로 둡니다. 과제 · 유전자 · 학습 시드는 서로 다른 변동원이므로, 구간이 어떤 단위로 계산되었는지 함께 읽습니다.

## 두 주장을 더 자세히

### 정렬과 정책의 연결 (R4 · C5 철회)

사전등록 주장 C5는 "계획기의 유효성과 표현의 유효성은 같은 주장"이라는 강한 연결이었습니다. 교차 모델 대조(R4)에서 모델 A의 정렬과 모델 B의 정책을 짝지어도 같은 모델끼리의 상관과 거의 같은 값이 나왔습니다(+0.3282 vs +0.3289). 같은 과제의 난이도가 여러 모델에 공통으로 작용한 결과로 읽히므로 C5는 철회했습니다([R6 수정 등록](../../results/geoacmg_final/findings/R6_amendment.json)).

19개 run에 대해 정렬 × 정책 곱으로 다시 계산하면 같은 모델 0.6354, 다른 모델 0.6350, 차이 +0.000424 [0.000169, 0.000766]입니다. 구간은 0을 배제하지만 크기는 매우 작습니다. 정렬과 행동은 함께 움직이는 부분이 있지만, 한쪽이 다른 쪽을 결정한다고 볼 근거는 약합니다.

### readout에 따라 달라지는 학습 좌표

같은 15개 학습 run을 여러 방식으로 읽은 정렬 정확도입니다.

| readout | 정렬 정확도 |
|---|---:|
| 각 모델의 자기 에너지 | 0.7405 |
| 표준화 cosine | 0.7199 |
| 일반 cosine | 0.5761 |
| L2 | 0.5697 |
| 음의 내적 | 0.5579 |
| whitening cosine | 0.4389 |

표준화 cosine이 자기 에너지의 성능을 대부분 되살리므로, 학습된 좌표는 자기 에너지가 아닌 방식으로도 읽힙니다. 7 시드로 늘린 비교에서도 cosine의 정렬 우위는 readout을 바꾸면 줄거나 뒤집혔습니다. 두 기하의 차이는 "표현 자체의 우열"보다 **공간을 읽는 방식과 표현의 조합**에서 나온다고 정리했습니다.
