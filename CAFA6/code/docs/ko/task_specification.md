# 작업 명세 (GO 용어 기반 단백질 기능 예측)

## 개요

단백질은 20가지 아미노산이 서열로 배열되어 이루어진 큰 생체분자입니다. 단백질의 아미노산 서열은 그 구조와 세포 내 기능적 역할을 크게 좌우합니다. 이 과제의 목표는 아미노산 서열로부터 단백질이 무엇을 하는지 예측하여 **Gene Ontology (GO)** 용어를 부여하는 모델을 구축하는 것입니다.

GO 용어는 단백질 기능의 세 가지 측면을 설명합니다.

- **분자 기능 (MF)**: 생화학적 활성(예: 결합, 촉매 작용)
- **생물학적 과정 (BP)**: 더 넓은 생물학적 목적(예: DNA 복구)
- **세포 구성요소 (CC)**: 세포 내에서 작용하는 위치(예: 핵)

예측은 **다중 라벨**(각 단백질은 여러 GO 용어를 가질 수 있음)이며, 라벨은 **계층적**입니다(GO는 DAG이므로 자식 용어는 부모 용어를 함의합니다).

## 문제 정의

단백질 아미노산 서열(FASTA 레코드)이 주어졌을 때, 확률과 함께 예측된 GO 용어 집합을 출력합니다.

- 입력: 단백질 ID + 아미노산 서열
- 출력: 0개 이상의 `(protein_id, go_id, probability)` 연관(association)
- 제약: 확률은 `(0, 1]` 범위여야 함(0은 불가)이며, 일반적으로 단백질당 관리 가능한 개수로 제한됨

예측 파일은 MF/BP/CC 연관을 하나의 목록으로 합쳐 담지만, 평가는 각 서브온톨로지별로 독립적으로 수행한 뒤 결합합니다.

## 전향적 평가 설정 (테스트 슈퍼셋 vs. 테스트 셋)

이는 **전향적(prospective)** 평가입니다. 제공된 테스트 데이터의 많은 단백질은 현재 실험적으로 부여된 기능이 없습니다.

- **테스트 슈퍼셋**: 예측을 생성해야 하는 모든 단백질(전체 추론 대상 목록)
- **테스트 셋(서브온톨로지별)**: 제출 마감과 해당 서브온톨로지의 평가 시점 사이에 **새로운 실험 검증 GO 주석**을 획득하는, 테스트 슈퍼셋의 숨겨진 부분집합

테스트 셋은 MF, BP, CC에 대해 각각 하나씩 총 3개가 존재합니다. 동일 단백질이 여러 서브온톨로지에서 새로운 실험 주석을 얻으면, 둘 이상의 테스트 셋에 포함될 수 있습니다.

학습 셋에는 최소 한 서브온톨로지에서 실험적으로 지지되는 GO 주석이 하나 이상 존재하는 단백질이 포함됩니다. 이들 중 일부는 테스트 슈퍼셋에도 나타날 수 있습니다.

파일 수준 상세(경로, 포맷)는 `docs/ko/dataset_description.md`를 참고하세요.

## 평가 지표 (정보-누적 가중 F1)

평가는 각 서브온톨로지에 대해 독립적으로 계산되는 **정보 누적(Information Accretion, IA)** 가중 정밀도/재현율에서 도출한 **최대 F-측도(F1)** 에 기반합니다.

- 예측 주석과 정답 주석을 비교하여 IA-가중 정밀도 및 재현율을 계산합니다.
- 예측 점수에 대한 결정 임계값을 스윕하여 다음에 대한 **최대** 가중 F1을 구합니다.
  - MF 테스트 셋
  - BP 테스트 셋
  - CC 테스트 셋
- 세 서브온톨로지 점수를 **산술 평균**으로 결합합니다.

### 가중치가 중요한 이유

GO는 계층적이며, 일반적인(상위) 용어는 더 구체적인(하위) 용어로부터 함의됩니다. 어떤 용어의 IA 가중치는 그 용어가 얼마나 정보량이 큰지를 반영합니다(단백질에서 자주 등장하는 용어는 가중치가 낮고, 드물고 구체적인 용어는 가중치가 높으며, 루트 용어의 가중치는 0입니다).

### 지식-획득(knowledge-gain) 하위 유형

평가는 제출 시점에 알려져 있던 정도에 따라(CAFA 스타일 평가에서 사용하는 용어) 단백질을 추가로 층화(stratify)할 수 있습니다.

- **무지식(No-knowledge)**: 제출 시점에는 해당 서브온톨로지에서 실험 주석이 없었지만, 이후에 일부가 생김
- **제한된 지식(Limited-knowledge)**: 제출 시점에 일부 실험 주석이 있었고, 이후 추가 주석이 생김
- **부분 지식(Partial-knowledge)**: 제출 시점에 세 서브온톨로지 모두에 실험 주석이 있었고, 이후 적어도 하나의 서브온톨로지에서 추가 주석이 생김

점수는 하위 유형별로(서브온톨로지 평균으로) 계산한 뒤, 최종 점수로 결합(하위 유형 평균)할 수 있습니다.

## 리더보드 참고 (분포 이동)

공개 리더보드는 테스트 슈퍼셋의 비교적 작은 단백질 부분집합에 기반할 수 있으며, 대략적인 지표로 의도됩니다. 최종 평가 셋은 향후 실험적 큐레이션에 의해 결정되므로, 공개 리더보드 단백질과 최종 테스트 단백질 사이의 분포 이동이 예상됩니다. 일반화 성능을 최대화하는 것을 목표로 하세요.

## 제출 포맷 (GO 용어 예측)

제출 파일은 **헤더 없이** 탭으로 구분되며, 한 줄에 하나의 연관을 기록합니다.

```
<target_id>\t<GO:nnnnnnn>\t<score>
```

규칙 및 제약:

- `target_id`는 테스트 슈퍼셋 FASTA 헤더의 단백질 ID와 일치해야 합니다.
- `GO:nnnnnnn`은 제공된 GO 버전의 유효한 GO 용어 ID여야 합니다. 유효하지 않은 용어는 평가에서 제외됩니다.
- `score`는 `(0, 1.000]` 범위여야 하며, 보통 **유효 숫자 3자리**까지 포함하도록 합니다.
- 점수 `0`은 허용되지 않습니다. 해당 쌍은 아예 생략하세요.
- 어떤 단백질 ID가 제출 파일에 **존재하지 않으면**, 그 단백질의 모든 예측은 0으로 간주됩니다.
- 파일 크기 제한을 위해, 각 타깃은 MF+BP+CC 합산 기준 **1500개 이하**의 연관 용어만 포함해야 합니다.

### 평가 중 온톨로지 전파(propagation)

제출된 예측이 GO 루트까지 이미 전파되어 있지 않다면, 평가자는 재귀적으로 전파할 수 있습니다.

- 각 부모 용어의 점수는 자식들의 점수 중 **최댓값**으로 설정됩니다.

이는 채점에 대해 온톨로지 일관성을 갖는 예측을 보장합니다.

## 선택 과제: 자유 텍스트 기능 예측

GO 용어 외에도, 단백질 기능을 설명하는 짧은 영어 텍스트 줄을 선택적으로 제출할 수 있습니다. 이는 대회 기간 중에는 평가되지 않으며 GO 리더보드에 영향을 주지 않지만, 충분한 사람이 작성한 설명이 축적되면 이후 평가될 수 있습니다.

포맷(동일한 단일 제출 파일 안에 포함):

```
<target_id>\tText\t<score>\t<text_line>
```

제약:

- 단백질당 최대 **5줄**(서로 다른 주장에 대해 서로 다른 신뢰도를 허용)
- 텍스트는 ASCII 출력 가능 문자 `33–126`을 사용하고, 공백(ASCII `32`)을 단어 구분자로 사용해야 합니다.
- 텍스트 줄에는 탭을 포함할 수 없습니다.
- 단백질당 총 텍스트 길이는(공백 포함) 모든 줄을 합쳐 **3000자**로 제한되며, 더 긴 제출은 잘릴 수 있습니다.

### 이후 텍스트 평가 방식(가능한 예)

- 1단계: 언어 모델을 사용해(예: UniProt의 사람 작성 설명과 비교) 자동 평가를 수행하고, 표준 요약(summarization) 스타일 지표로 상위 팀을 선별
- 2단계: 상위 후보에 대해 참조 설명과 비교하는 사람 평가

두 가지 흔한 시나리오:

- 문헌은 공개되어 있으나 제출 시점에 아직 UniProt에 요약되어 있지 않은 경우(요약 문제에 더 가까움)
- 공개 문헌이 거의 없거나 전혀 없는 경우(서열 및 다른 신호를 활용한 기능 추론이 필요)

## 참여 참고 (학술 논문)

주최 측은 대회 종료 후 이벤트를 설명하는 학술 논문을 작성할 수 있습니다. 일부 대회는 잠재적 공저자 고려를 위한 옵트인 절차를 제공하며, 선정은 기여도에 기반할 수 있습니다.
