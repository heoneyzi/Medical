# ⚙️ configs

One YAML file drives every `python -m vcc_baselines` command. Blocks: `data` (paths and column names), `gwps` (reference screens used as the effect library), `esm2`, `embed` (precomputed context embeddings), `predict` (method, effect type, generator, similarity space, τ, scale, shrinkage, seed), `submit` (2026 packing rules) and `eval`.

| File | Purpose |
|---|---|
| [`synthetic.yaml`](synthetic.yaml) | Offline demo used by `scripts/quickstart.sh` ([E0](../experiments/E0_synthetic_smoke/README.md)): 400 synthetic genes, 50 cells per target; ESM-2 uses a deterministic random fallback, which exercises the plumbing but carries no biology |
| [`real_example.yaml`](real_example.yaml) | Template for a real challenge run: 18,533-gene panel, 400 cells per target, contexts A/B/C, Replogle K562 / RPE1 as sources, official `vcc` packer. Fill the paths after `vcc datasets download controls` |
| [`external_frozen_models.yaml`](external_frozen_models.yaml) | Registry of external frozen encoders (UCE-4L, TranscriptFormer, scGPT, scFoundation, scPRINT-2, gated priors): official repo, pinned commit, checkpoint hash, required runtime files, exact command, output key and dimension |
| [`data_policy_replogle_only.yaml`](data_policy_replogle_only.yaml) | Strict response-source policy for [E3](../experiments/E3_replogle_only_strict/README.md): only Replogle K562 / RPE1 responses allowed; other perturbation datasets forbidden; encoders allowed only as representations; no external truth for tuning |

Shadow-benchmark configs (`shadow.yaml`) are generated by `prepare-shadow` next to each split. The two Replogle-only configs generated for E3 are stored in [`../experiments/E3_replogle_only_strict/results/configs/`](../experiments/E3_replogle_only_strict/results/configs/).
